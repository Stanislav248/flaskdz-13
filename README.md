# calorie-app

1. `npm install`
2. `npx expo install react-native-web react-dom @expo/metro-runtime`
3. `npx expo start`  (у браузері: клавіша `w`)

Картинки для заміни:
- assets/images/hero.png — ілюстрація з авокадо на екрані привітання
- assets/icons/plan.png, menu.png, diary.png, tip.png — іконки нижньої навігації
